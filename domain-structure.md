# Структура доменного имени моего сайта  
*Актуально на 13 января 2026 года*

Доменное имя — это удобочитаемый адрес сайта в интернете, который заменяет сложный числовой IP-адрес. Оно организовано иерархически справа налево, от самого общего уровня к самому конкретному.

Рассмотрим структуру доменного имени моего сайта:  
**`https://ваш-логин.github.io`**

## Уровни иерархии доменного имени:

1. **Корневой домен (Root Domain)**  
   Обозначается точкой (`.`) в конце полного доменного имени, но обычно скрывается. Например: `ваш-логин.github.io.`  
   Этот уровень управляется корневыми DNS-серверами.

2. **Домен верхнего уровня (Top-Level Domain, TLD)**  
   → `.io`  
   Это домен верхнего уровня. Хотя `.io` изначально был национальным доменом Британской территории в Индийском океане, сегодня он популярен среди разработчиков и стартапов.

3. **Домен второго уровня (Second-Level Domain, SLD)**  
   → `github`  
   Это имя сервиса, зарегистрировавшего зону в домене `.io` — в данном случае, GitHub.

4. **Поддомен третьего уровня (Subdomain)**  
   → `ваш-логин`  
   Это ваше уникальное имя пользователя на GitHub. Оно указывает на ваш персональный сайт, размещённый через GitHub Pages.

Таким образом, иерархия домена выглядит так:
ваш-логин     → поддомен (уровень 3)
   ↓
github        → домен второго уровня (уровень 2)
   ↓
io            → домен верхнего уровня (уровень 1)
   ↓
.             → корневой домен (уровень 0)

Эта структура позволяет системе DNS точно определить, где находится ваш сайт, и направить пользователя по нужному адресу.

> 💡 **Примечание**: Если вы подключите собственный домен (например, `mysite.com`), структура изменится: `www.mysite.com` будет содержать поддомен `www`, основной домен `mysite` и TLD `.com`.
