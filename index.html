Решение шифров Цезаря:

  1. Определение ключей шифра Цезаря:

    • а. АПЕЛЬСИН → САЦЬНВЩЮ
      Ключ: 18
    • б. АБРИКОС → ЫЬЛГЕЙМ
      Ключ: 28 (эквивалентно –4 по модулю 32)

  2. Расшифровка сообщений:

    • а. ФХНЗКЧ → ПРИВЕТ (ключ = 5)
    • б. ЦЩЕБФ → ВЕСНА (ключ = 20)

  3. Шифрование фамилии с ключом 10:
    Пример для фамилии КАЛДАРОВА:
    К→Ф, А→К, Л→Х, Д→О, А→К, Р→Ъ, О→Ш, В→М, А→К, → ФКХОКЪШМК.
